## 能压哪些文件，和在线压缩工具差在哪

支持的格式基本覆盖了日常办公会遇到的那几类：

- Office 文档：PPT／PPTX、DOC／DOCX、XLS／XLSX
- PDF 文件
- 图片：JPEG、PNG、TIFF
- 上面这些文件被打包在 zip 里，也能一起处理

压完保留原扩展名，这是它和普通压缩软件最本质的区别。7-Zip、WinRAR 是把文件装进一个盒子，收件人得先解压；NXPowerLite 是把文件本身变瘦，发出去还是 .pdf、.pptx，对方双击就开。官方页面写的最高压缩率是 95%，这个数字取决于文件里有多少冗余的图片和嵌入对象，实际能压掉多少得看你自己的文件。

几个规格值得记一下。批量单次最多 10,000 个文件，处理积压的历史文档够用，偶尔遇到超大目录要分两批。文件大小没有上限，50MB 到 1GB 以上的文件都能吃。整个过程 100% 离线，文件不上传任何服务器，这对有保密要求的公司是硬指标。

集成的部分对重度 Office 用户比较实用。装完之后 Outlook 里会多一个插件，你点发送的瞬间附件自动被压一遍，收件人收到的还是原格式。Windows 资源管理器和 Mac 访达里也有右键菜单，选中文件直接压，不用先打开主程序。PowerPoint、Word、Excel 里同样有加载项。

至于它和 iLovePDF 这类在线工具谁压得更小，没有通用答案。一份塞满高清照片的 PPT，两边都能砍掉大半；一份本来就没什么冗余的文档，换什么工具都压不动。别指望换个软件把 20MB 变成 1MB。真正的差别在流程：在线工具一次一个文件，免费档通常还有 10MB 到 25MB 的体积限制，敏感文件上传前你得想一想；NXPowerLite 是你把一整个文件夹拖进去，去泡杯茶，回来就压完了。
